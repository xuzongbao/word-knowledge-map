# Logo / 技能图标

正式选用：**方案 C · 词汇树徽章**（一眼就会的单词 + 词汇知识树）。

## 文件

| 文件 | 用途 |
|------|------|
| `icon.png` / `icon-512.png` | 多数 Skill Hub 主图标（512×512） |
| `icon-1024.png` | 高清源图 / 宣传物料 |
| `icon-256.png` `icon-128.png` `icon-64.png` | 列表缩略、侧栏 |
| `word-knowledge-map-logo.png` | 设计稿 master 备份 |

Skill 包内同步：`skills/word-knowledge-map/assets/icon.png`

## 上传建议

- 方形 PNG，透明或奶油底均可；本版为奶油圆角徽章构图。
- 优先传 **512×512**；若平台要求更小，用 128 或 256。
- 小尺寸下边缘细节会弱化，属预期；列表场景以 512 裁切预览为准。

风格与 skill 手绘教学海报一致：奶油纸感、珊瑚/深蓝强调、知识地图隐喻。
