# 成图风格规范（Style Lock）v1.2

对齐参考图：`references/style-target-care.png`

## 一句话

手绘涂鸦风儿童英语教学海报：中央核心词向外发散四张圆角卡片，底部一条彩色知识链；马卡龙配色；每块带小插画；英文加粗醒目，例句里目标词彩色高亮。

## 版式模式

卡面数量与标题跟 `layout_plan.mode`（见 `layout-modes.md`），不要无论什么词都强制「短语→形→副→名」四象限。
`full-family` 才用经典四象限；`phrasal-hub` / `function-word` / `compact-three` 按对应骨架。

## 画幅与层级

- 比例：16:9 横向
- 层级从上到下：标题区 → 中央 Hub + 四象限 → 底部知识链 + 口号
- 信息靠「关系」组织（词根 → 短语 → 形容词 → 副词 → 名词），不要做成词典条目墙

## 配色

- 背景：米白 / 浅奶油色，可有极淡纸感/细微纸纹；**不要**响亮几何点阵网格（planner Soft UI 征象）
- 卡片描边与色块：浅蓝、薄荷绿、浅紫、浅黄、软橙（马卡龙）
- 目标英文短语/单词强调色：红或深蓝（与正文区分）
- 阴影：软、浅，不要厚重拟态

## 字体与文字

- 英文：圆润无衬线、加粗，明显大于中文
- 中文：清晰无衬线（如 Noto Sans CJK），字重中等
- 音标：小于单词，可读即可
- 例句：一行英 + 一行中；目标词/短语彩色加粗
- 禁止：艺术字扭曲关键英文、字体重叠、字号小到难读

## 模块写法

### 标题区
- 主标题：`看一眼就会的单词 👀 之 {word}`
- 可选手绘下划线、星星点缀
- 副标题：`从一个单词，串起小学到初中的完整知识脉络`

### 中央 Hub
- 小胶囊标签：`核心词`
- 大号 `{word}`
- 音标 + 核心中文义
- 手绘感曲线箭头指向四象限

### 知识卡片（full-family 时为四象限；其他 mode 卡数见 layout-modes）
每张上图卡片必须包含：
1. 短标题（如「基本用法」「care 的更多用法」「careful → carefully」）
2. 2–4 条知识点（短语/派生词 + 中文）
3. 至少 1 条完整短例句（英+中），目标词高亮
4. 至少 1 个相关小插画（人物/物品/表情），贴合该条语义

左上优先：短语动词 / 基本用法  
右上优先：形容词派生  
左下优先：副词派生  
右下优先：名词派生或其他延伸  

### 底部知识链
- 彩色圆角胶囊 + 箭头横向串联
- 文案必须来自 layout_plan.knowledge_chain；完整词族示例：`{word}（词根）→ 短语动词 → 形容词 → 副词 → 名词`；弱词族勿套假链
- 口号：`一张图，记住整个脉络` / `一个单词，串起一整条知识链！`

## 插画

- 风格：可爱、简洁、手绘感，与卡片同色系
- 作用：记忆锚点，不是装饰噪音
- 数量：每象限 ≥1；不要大面积插画盖住文字

## 明确不要

- 扁平商务 dashboard / 无插画纯色块墙
- 把「第三人称/过去式」大表做成主模块（除非用户点名要语法变位图）
- 霓虹、赛博、照片拼贴、复杂立体场景
- 为美观牺牲拼写与中文正确性

## 程序化排版时的注意

若用 HTML/CSS 出图：
- 用圆角、虚线/手绘风边框、柔和阴影模拟 doodle
- 插画可嵌入小图或简洁 SVG
- 仍须满足本规范的信息结构与配色，避免做成「普通网页截图感」


## 反例锁（v1.1.1 新增，非常重要）

上一版失败教训：版式对了，但气质做成了「干净 Soft UI / 现代教材 App」。

**最终成图如果像下面这些，一律判失败并重做：**
- 扁平卡片墙、细直线连接、极简线性图标（爱心线标、简单 emoji 替代卡通）
- 完美对齐的数字产品界面感、Neumorphism / Soft UI
- 无卡通人物、只有装饰性小 icon
- 标题用普通无衬线，没有手写/粉笔感

**必须像参考图：**
- 手帐 / 老师白板 / 涂鸦海报
- 手写感标题（可用站酷快乐体、马善政体等手写中文字体）
- 粗、弯、略不匀的手绘箭头（不是 1px 细线）
- 每个象限有「小孩卡通角色场景」插画（ magnifying girl、困惑男孩、读书女孩等）
- 卡片边框略不完美、可轻微旋转 0.5–1.5°
- 奶油纸 + 点阵底纹

参考锚点：`references/style-target-care.png`


## 对照翻车清单（相对参考图）

若出现以下任一项，判失败：
1. 白底浮起卡片 + 柔和投影（网页 Soft UI）
2. 细直线/细spoke 连接中心与模块
3. 中心不是黄底手绘框 +「核心词」色胶囊
4. 边框完美几何圆角、无马克笔抖动感
5. 插画只有扁平小 icon，没有场景感卡通小孩
6. 整图像组件拼装界面，而不像一张手帐海报画完

成功特征（参考图）：
- 奶油点阵纸 + 蜡笔/马克笔填色纹理
- 边框略歪、可有虚线内框
- 粗弯蓝色手绘箭头
- 黄底核心词 hub
- 四象限彩色底/彩边 + 标题胶囊
- 底部云朵/波浪标语 + 真实短语胶囊链
